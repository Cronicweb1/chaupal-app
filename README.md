# Chaupal App

Flutter app preview repository for Chaupal.

## Android APK preview

The intended preview flow is to build the Flutter project with GitHub Actions and publish the resulting release APK under `previews/` for easy testing.

### Current status

The supplied frontend archive contains the Flutter source, but no `.apk` or `.aab` binary was included. The repository is therefore created and ready for the source/build pipeline, but there is not yet an APK to download from the repository.

## App areas

- Ludo
- Carrom
- Snakes & Ladders
- Tic-Tac-Toe / UTTT
- Adda/social feed
- Chat
- Cups/leagues
- Market and virtual economy
- Profiles and onboarding
- Sound and haptics

## Backend

The Chaupal backend is maintained separately from this Flutter preview repository.
